# Asset inventory — 2.5D only

The landscape, bean plant, roots/nodules, cow, soil layers, microbes, groundwater and nitrogen particles are drawn by the recovered Canvas scene in `src/scene.js`, with the existing visibility/interaction improvements in `src/clarity.js`. No imported model is used.

`src/assets/microbes-atlas.png` and `src/assets/nostoc-commune.png` are the existing educational bacteria illustrations. The offline build embeds them as data images; the website copies them locally. They are illustrative teaching examples, not microscope photographs or species-identification evidence. All seven existing named cards and optional scientific-reference links are preserved.

Fonts use installed system serif/sans-serif families. Audio is generated locally through Web Audio. No external fonts, audio files, textures or APIs are needed at runtime. Scientific-reference links are optional and open only when deliberately selected.

The three supplied model copies and all 3D assets, vendor libraries, working copies, model previews/metadata and old 3D exports have been removed from this project. Original user files outside the project were not modified.
